AgriCore v1.4 - GPS Return Journey
==================================

WHAT THIS UPDATE ADDS
---------------------
- Outward Start Travel and Arrived On Site GPS capture.
- Optional return-journey prompt after a completed job is submitted.
- Start Return Journey and Return Complete actions.
- Return GPS and timestamps stored in job_travel_sessions.
- Outward and return travel summaries on the technician job.
- Technician status set to travelling during the return journey.
- Technician status restored to completed when the return is finished.
- Existing office travel-editing route remains available before invoicing.
- No continuous or background GPS tracking.

INSTALLATION
------------
1. Extract this ZIP into:
   C:\projects\Agricore\frontend

2. Run in Supabase SQL Editor:
   supabase/migrations/20260804_gps_return_journey.sql

3. Build:
   taskkill /F /IM node.exe
   Remove-Item ".\.next" -Recurse -Force -ErrorAction SilentlyContinue
   npm.cmd run build

4. Start locally:
   npm.cmd run dev

TEST SEQUENCE
-------------
1. Open an assigned job as a technician.
2. Press Start Travel and allow location permission.
3. Press Arrived On Site.
4. Start and stop labour, then complete and submit the job.
5. Choose Yes when asked about the return journey.
6. Confirm the return journey starts and Dispatch shows travelling.
7. Press Return Complete.
8. Confirm the outward and return minutes are displayed.
9. Review/edit the travel from the office before invoice approval.
10. Choose No on another completed job and confirm no return session is made.

NOTES
-----
- Browser GPS requires HTTPS in production. Localhost is permitted for testing.
- If location permission is denied, the journey can still be recorded without coordinates.
- The return journey is optional because technicians may travel directly to another job.
