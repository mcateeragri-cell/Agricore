AgriCore Platform Control Centre - Launch Candidate

Install
1. Extract this ZIP over C:\projects\Agricore\frontend
2. Allow Windows to replace existing files.
3. Run: npm.cmd run build
4. Run: npm.cmd run dev -- --webpack
5. Sign in as an AgriCore super_admin/platform_admin and open /platform

Included
- Platform dashboard restricted to super_admin/platform_admin
- Company register
- Subscription overview with MRR/ARR
- Trial monitoring
- System health page
- Platform navigation for platform administrators only
- Starter/Professional/Enterprise commercial plan summary
- Add-on roadmap shown as coming soon (not billable yet)
