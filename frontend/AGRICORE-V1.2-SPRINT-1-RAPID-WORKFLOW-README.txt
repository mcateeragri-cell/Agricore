AgriCore v1.2 — Sprint 1: Rapid Workflow Finish

AUDIT-FIRST RESULT
The latest uploaded project already contained:
- Inline customer creation inside New Job
- Inline machine creation inside New Job
- Automatic selection of newly-created customer/machine
- Minimal quick-entry fields
- Invoice billing-detail validation
- Existing Calendar, Offline, Service Programmes, Data Management and Deletion Engine foundations

Those features were NOT duplicated.

THIS SPRINT ADDS
1. Emergency Callout mode directly inside the existing New Job workflow.
   - One-click Emergency Callout button
   - Automatically sets priority to urgent
   - Quick fault-category chips:
     Engine
     Hydraulics
     Electrical
     Transmission
     PTO
     Air Conditioning
     Other
   - Uses the existing inline customer/machine drawers rather than creating another wizard/route
   - Existing job details remain in place

2. Customer profile-completeness indicators.
   - Customers created rapidly can still be saved with only a name
   - Customer list now flags records missing phone/address/postcode
   - This is informational only; it does not slow down job creation
   - Existing invoice validation remains the final billing safeguard

3. Machine profile-completeness indicators.
   - Machine list flags records missing year, identification (registration or serial), or hours
   - No extra fields are made mandatory during rapid callout entry

NO SQL MIGRATION REQUIRED.
NO NEW ENVIRONMENT VARIABLES.
