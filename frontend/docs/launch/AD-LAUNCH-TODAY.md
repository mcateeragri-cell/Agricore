# AgriCore — Ad Launch Today

## Before spending
Confirm production tracking IDs are configured and cookie consent works:
- Google Analytics
- Meta Pixel (if launching Meta)
- LinkedIn Insight Tag (if launching LinkedIn)
- Microsoft Clarity (optional but useful)

Test these conversions yourself:
- demo_cta_clicked
- product_demo_clicked
- trial_cta_clicked
- demo request completed
- trial signup completed

## Google Search — launch first
Use the existing campaign build sheet and matching landing pages.

Initial campaign groups:
1. Agricultural Engineering Software
2. Farm Machinery Workshop Software
3. Mobile Job Sheets
4. Machinery Service Management

Start with phrase/exact-style high-intent terms. Review search terms daily during the first week.

### Core negative themes
Exclude irrelevant consumer/farm-management traffic where appropriate, e.g.:
- farming game
- tractor game
- farming simulator
- free spreadsheet
- agriculture degree
- farming jobs
- tractor parts (unless intentional)
- machinery for sale

## Meta
Do not use broad cold Meta spend as the first proof channel. Start with:
- website retargeting once an audience exists
- product-demo viewers
- ROI visitors
- demo page visitors who did not enquire

Creative angles:
- "Still running service jobs through paper, WhatsApp and spreadsheets?"
- machine history + digital job workflow
- mobile technician workflow
- AI Workshop Assistant

## LinkedIn
Use small tests for higher-value buyers:
- Service Manager
- Workshop Manager
- Dealer Principal
- Operations Manager
- Owner / Director

Prioritise machinery dealers and multi-engineer service businesses. Compare cost per qualified demo, not cost per click.

## UTM format
utm_source={{google|meta|linkedin}}
utm_medium={{cpc|paid_social}}
utm_campaign={{market}}_{{audience}}_{{theme}}
utm_content={{creative}}
utm_term={{keyword when relevant}}

Example:
?utm_source=google&utm_medium=cpc&utm_campaign=uk_ag_eng_software&utm_content=rsa1&utm_term=agricultural%20engineering%20software

## First 72 hours
Do not make large decisions from a handful of clicks.
Check:
- tracking works
- search terms are relevant
- landing pages load well on mobile
- enquiries contain UTM/referrer data
- spend is not leaking into irrelevant terms
