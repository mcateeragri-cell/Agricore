# AgriCore — First 100 Customers Playbook

## Objective
Get AgriCore in front of agricultural engineering businesses quickly, learn what converts, and use real customer behaviour to guide the next product work.

## Core offer
- 14-day free trial
- £0 charged today
- Starter £49/month + VAT
- Professional £89/month + VAT
- Enterprise £225/month + VAT
- Founding Customer Programme for early businesses willing to test real workflows

## Primary conversion paths
1. Search ad -> intent landing page -> Start free trial
2. Search ad -> intent landing page -> Book demo
3. Social/LinkedIn -> homepage/industry page -> Explore demo -> trial/demo
4. Direct outreach -> Founding Customer Programme -> tailored demo

## Initial markets
Launch English-language campaigns first so sales/support remain manageable:
- United Kingdom
- Ireland
- Australia
- New Zealand
- Canada
- United States

Do not run all countries with one undifferentiated budget. Use separate campaigns or geo groups so cost and conversion can be compared.

## First launch targets
Track these as the primary weekly numbers:
- qualified website sessions
- product demo opens
- ROI calculator usage
- demo requests
- trial signups
- activated trials (company created + first customer/machine/job)
- paid conversions

## Recommended first offer
Do not lead with discounts. Lead with relevance and setup help:

"Join AgriCore as a founding customer. Test the platform on real agricultural service work with a 14-day trial, practical onboarding and a direct feedback route."

## Budget rule
Start small. Increase spend only after the correct conversions are measurable. Do not optimise for clicks alone.

Suggested testing pattern:
- Google Search: highest priority
- Meta: awareness + retargeting once enough traffic exists
- LinkedIn: targeted dealer/service-manager tests with tight budgets

## Weekly decision rule
Every Friday, identify:
1. Which campaign generated demos/trials?
2. Which landing page converted best?
3. Which search terms were irrelevant and should be excluded?
4. Where did users drop out between landing page and signup?
5. What did demo prospects repeatedly ask for?

Build only from repeated evidence, not one-off requests.
