# AgriCore — 20 Minute Demo Runbook

## 0-3 min — Understand the business
Ask only what changes the demo:
- How many engineers/technicians?
- Workshop, mobile service, or both?
- What software/paper process is used today?
- Biggest admin frustration?
- Which machines/brands are commonly supported?

## 3-6 min — Customer + machine
Show that AgriCore is machine-centred:
- customer record
- machine record
- registration/serial/hours
- previous jobs/service history

## 6-11 min — Job workflow
Show one end-to-end job:
- create/assign job
- technician workflow
- travel/labour
- parts
- photos/signature
- completion

Do not show every setting.

## 11-14 min — Commercial flow
Show whichever is relevant:
- quote -> job -> invoice
- stock/purchase orders
- service programmes

## 14-16 min — AI Workshop Assistant
Use a realistic complaint and explain clearly:
- it uses machine/job context where available
- it is advisory
- manufacturer documentation remains authoritative for specifications/safety-critical decisions

## 16-18 min — Their problem
Return to the problem they gave in minute one. Show the exact AgriCore workflow that addresses it.

## 18-20 min — Next step
Offer one clear next action:
- start the 14-day trial now
- schedule onboarding
- add a small set of real customers/machines and run one week of jobs

Do not pressure a prospect into Enterprise if Professional fits their workflow.

## After the call
Record:
- business size
- country
- current system
- strongest interest
- objections
- requested feature
- next action/date
