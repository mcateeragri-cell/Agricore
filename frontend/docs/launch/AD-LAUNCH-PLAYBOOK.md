# AgriCore Advertising Launch Playbook

## Primary objective
Generate qualified free-trial starts and tailored demo requests from agricultural engineering and machinery-service businesses.

## Core positioning
**Run your agricultural engineering business from one platform.**

Supporting proof points:
- Customer and machine history stay connected.
- Workshop jobs and field callouts use the same operational record.
- Technician Pro captures travel, labour, parts, photos and signatures from a phone.
- Stock, purchasing, quotes and invoices connect to day-to-day service work.
- AI Workshop Assistant can use recorded machine and job history as diagnostic context.

## Launch markets
Start with English-speaking markets where the current product and support experience are easiest to deliver:
1. United Kingdom
2. Ireland
3. Australia
4. New Zealand
5. Canada
6. United States

Run each country separately so budget, cost per lead, trial rate and message performance remain measurable.

## Landing pages
Use intent-specific destinations instead of sending every advert to the homepage:
- `/industries/agricultural-engineers`
- `/industries/machinery-dealers`
- `/industries/mobile-service-engineers`
- `/industries/dairy-service`
- `/pricing`
- `/contact`

## UTM convention
Use consistent campaign tracking on every paid destination:

`?utm_source=google&utm_medium=cpc&utm_campaign=uk_agricultural_engineers&utm_content=job_management`

Sources: `google`, `meta`, `linkedin`
Mediums: `cpc`, `paid_social`
Campaign: `{country}_{audience}`
Content: `{creative_or_message}`

The public demo/contact form already captures UTM source, medium and campaign into the AgriCore launch-lead inbox.

## Google Search structure
Start narrow. Do not mix high-intent workshop software searches with broad farming keywords.

Campaigns:
- Agricultural engineering software
- Farm machinery workshop software
- Field service / mobile job cards
- Machinery dealer service software

Initial keyword themes:
- agricultural engineering software
- agricultural workshop software
- farm machinery workshop software
- farm machinery service software
- agricultural service management software
- agricultural engineer job management
- mobile job sheets agricultural engineers
- machinery service CRM
- machinery dealer workshop software
- field service software agricultural engineers

Negative keyword themes to review early:
- jobs / careers / salary
- degree / course / university
- tractor for sale / machinery for sale
- free download / cracked
- farming game

## Meta launch
Use short demo clips and screenshots. Test messages rather than creating dozens of audiences at once.

Creative angles:
1. **Paperwork problem** — paper job sheets, WhatsApp and spreadsheets versus one connected job.
2. **Machine history** — every repair and service attached to the machine.
3. **Technician mobile** — labour, parts, photos and signatures from the field.
4. **AI Workshop** — diagnostic assistance grounded by company machine history.

Primary conversion: free trial.
Secondary conversion: demo request.

## LinkedIn launch
Prioritise higher-value organisations: machinery dealers, larger independent engineering firms and service managers.

Job-function themes:
- Owner / Managing Director
- Service Manager
- Workshop Manager
- Aftersales Manager
- Agricultural Engineer
- Operations Manager

Use the dealer landing page for dealer/service-management campaigns and the agricultural-engineer page for independent workshops.

## Budget discipline
Do not scale on clicks alone. Track:
- Landing-page visits
- Demo requests
- Trial starts
- Activated trials (company set up and first meaningful record created)
- Paid conversions

Increase spend only when a campaign produces qualified trials or demo conversations at a sustainable cost.

## First creative set
Create at minimum:
- Desktop dashboard screenshot
- Technician mobile screenshot
- Machine history screenshot
- AI Workshop screenshot
- 20–30 second product workflow screen recording

Avoid stock photography where an actual AgriCore product screen can demonstrate the value more credibly.

## Safety / claims
Do not claim the AI Workshop Assistant replaces manufacturer service information or guarantees diagnosis. Position it as diagnostic assistance using AgriCore context with manufacturer verification required for specifications and safety-critical decisions.
