AgriCore v1.1.2 — Data Management

WHAT THIS RELEASE ADDS
- Administration -> Data Management
- Bulk selection, search and CSV export
- Permanent deletion for test Jobs with dependency-aware cleanup
- Jobs linked to invoices are protected
- Customer deletion only when no machines/jobs/quotes/invoices are linked
- Machine deletion only when no jobs/quotes/invoices are linked
- Quote deletion limited to draft/rejected/cancelled records
- Invoice deletion limited to draft records
- Stock items are archived (active=false) rather than deleting movement history
- Users are deactivated at company-membership level rather than deleting their authentication account
- Current signed-in user cannot deactivate their own membership
- Destructive operations require typing DELETE

NO SQL MIGRATION REQUIRED.

IMPORTANT SAFETY BEHAVIOUR
Data Management is intentionally restricted to company administrators, administrators, platform admins, or accounts with settings.manage.
Sent/paid invoices and live linked customer/machine history cannot be permanently removed through this tool.

JOB CLEANUP
When a deletable job is removed, AgriCore clears known job child records first (assignments, labour, parts, photos, travel, completions) and nulls optional service/stock references before deleting the job. Optional module tables are tolerated if they are not present in a particular installation.

INSTALL
Extract this ZIP over:
C:\projects\Agricore\frontend

Then run:
taskkill /F /IM node.exe
Remove-Item ".next" -Recurse -Force -ErrorAction SilentlyContinue
npm.cmd run build
npm.cmd run dev -- --webpack

TEST
1. Open Administration -> Data Management.
2. Select Jobs.
3. Select several old development jobs with no linked invoice.
4. Click Delete selected and type DELETE.
5. Confirm the jobs disappear from Data Management and /jobs.
6. Confirm a job linked to an invoice displays Protected and cannot be selected.
7. Test Customers/Machines: linked records should be protected; unused test records can be deleted.
8. Test Quotes: draft/rejected/cancelled only.
9. Test Invoices: draft only.
10. Test Stock: archive an item and confirm it no longer appears as active stock.
11. Test Users: deactivate a test membership and confirm the user cannot access that company; your own membership remains protected.
12. Export a CSV from any tab.

DEPLOY
After a successful local build, commit the new data-management page/API plus navigation-data.ts and push to main.
