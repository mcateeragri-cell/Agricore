AgriCore ZIP 1 — Core CRM multi-company isolation

Extract the CONTENTS of this ZIP into:
C:\projects\Agricore\frontend

Allow Windows to overwrite matching files.

Included:
- Dashboard summary cards
- Dashboard recent jobs
- Dashboard schedule
- Customer list/create
- Customer detail and machine creation
- Machine list
- Machine detail, editing and hour readings

After extracting:
1. Restart the TypeScript server in VS Code.
2. Run: npm run build
3. Run: npm run dev
4. Switch between companies and test Dashboard, Customers and Machines.
